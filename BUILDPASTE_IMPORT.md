# BuildPaste Import

BuildPaste ([buildpaste.net](https://buildpaste.net)) is an **import source only**.
It is never contacted during gameplay or ordinary Gradle builds.

## Public discovery

The tooling uses public pages:

- `GET /search/__data.json?q=...` (SvelteKit data)
- HTML search/category pages as fallback

Batches are small (≤20), paced, cached under `.livingmods-cache/buildpaste/` (gitignored).

## Structure payloads

BuildPaste delivers block data through the authenticated Minecraft mod `/paste` flow.
There is **no public NBT download endpoint**. The importer therefore records:

```
SOURCE_UNAVAILABLE
```

for structure payloads and continues. Premium content is skipped (never bypassed).

## Production content

Because BuildPaste payloads are not publicly downloadable, MineLife ships a large
**authored** culture-distinct MLS library generated by:

```
./gradlew :livingmods-tools:installDist -x test
./livingmods-tools/build/install/livingmods-tools/bin/livingmods-tools culture-library author
```

Authored assets use culture silhouette rules (longhouse proportions, courtyards,
pagoda layers, yurts, roundhouses, underground foundations, etc.) — not palette swaps.

## CLI

```
culture-library search --query "viking house" [--limit 20]
culture-library import --culture avalon
culture-library resume
culture-library validate
culture-library report
culture-library author
culture-library names
```

Query plans live in `livingmods-tools/src/main/resources/culture-library/query_plans/`.

## Statuses

`DISCOVERED`, `FETCHED`, `VALIDATED`, `IMPORTED_EXACT`, `IMPORTED_SANITIZED`,
`AUTHORED`, `DUPLICATE` (+ rotation/mirror/near), `INVALID_SOURCE`,
`UNSUPPORTED_BLOCKS`, `WRONG_CATEGORY`, `SOURCE_UNAVAILABLE`, `QUARANTINED`.

## Offline reproducibility

Once MLS + manifests are in the repository, `./gradlew buildAll -x test` packages
them without network access.
